## Review follow-up — 2026-09-13

Implemented the critique's core local workflow fixes:

- Saved attendance is returned by the day API and restored in Today; unsaved attendance defaults to unknown. School-local date initialization replaces UTC date selection.
- Scoped planning data supplies topic names, source labels/previews, and approved source checkboxes. Teachers can add an occurrence and enter move destinations.
- Full question/answer/rationale review, source previews, and a content editor create a new revision before approval.
- Student progress and selected answers restore on reopen. Submission requires all steps and questions; submitted answers cannot be changed. Rapid completion updates merge rather than replacing each other.
- Teacher Exceptions displays learner names, submitted status, and resolution controls. Resolving help clears its flag and permits a subsequent request.
- The agent receives the complete packet JSON schema and an instruction to treat source text as evidence rather than commands. This is not model-runtime proof.
- Citation validation rejects wrong page labels and fabricated direct excerpts.
- Worker supervisor renews leases, bounds child execution to 300 seconds, and marks exhausted expired attempts failed. Superseded attempts cannot mark a newer attempt failed.
